This repository contains a large and continuously growing collection of Python projects.

The projects are primarily created to:

- Practice problem-solving and programming logic

- Turn concepts into working programs

Not every project here is intended to be a complete real-world application. Many are small projects and practice programs created specifically to make sure I can **understand a concept and actually use it in code**.

As I learn more Python, I will continue adding new projects and gradually increase their complexity.
